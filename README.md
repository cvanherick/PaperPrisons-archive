# Team message archives

[Open the archive website](https://cvanherick.github.io/PaperPrisons-archive/)

Choose **Paper Prisons / Juneteenth Expungement** or **Tech Bono**, then enter the username and password shared with you by your team administrator. Search by keyword, channel, person, or date, and open a conversation to read its saved replies.

No GitHub account, download, or installation is needed. Contact the team administrator for access or password changes. Use **Lock archive** when finished on a shared computer.

This repository holds the public viewer and, after administrator setup, encrypted archive bundles. Readable messages, reader passwords, and publishing credentials belong only in the separate private source repository and its Actions secrets.

The website requires its initial encrypted publication before logins can unlock any messages. The administrator should enable GitHub Pages from `main` / `/(root)` and follow `docs/encrypted-site.md` in the private source repository.
